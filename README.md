# 姐儿妹儿拼音练习器 

### ===== 中文不易，多加努力 ：）=====

#### 给外国出生的孩子学中文设计
#### 他们的学习路径和国内的孩子以及学习中文的外国人不同
#### 他们有一定的基础，不需要像外国人从零开始，会让他们觉得无趣
#### 他们日常极少使用中文，所以国内孩子的成长曲线不适用于他们
#### 所以只能另辟蹊径

<Br>

#### 1，文本自动增加拼音
* 导入文本自动添加拼音，自选适合他们的文章

#### 2，生字练习
* 字卡形式帮助孩子回顾所选文章中的生字

#### 3，词汇模式
* 可以根据当天学习，添加相关词组并生成字卡

#### 4，汉字模式
* 去除拼音，让孩子通过打字去验证生字的熟练度

#### 5，聊天模式*
* 内网聊天功能，发送中文，显示为中文加拼音，模拟现实，增加趣味

#### 6，自定义设置
* 通过远程文本文件导入功能，实现一次更改，所有客户端同步
* 通过custom.txt实现多音字纠正。

#### 备注*:聊天功能通过内网IP广播形式发送，所以启动第一次时，会有windows防火墙提示，请选择“允许”。
